# Topics
- HTTP
    - contains request line, request headers and body
    - Request line
        - HTTP methods(GET/POST/PUT/DELETE)
        - request target(ex. URL)
        - HTTP version
    - Request header
        - Providing information about the request or the desired response
        - consist of a number of key-value pair
    - body 
     - the actual content that we want to deliver
     - The formats of HTTP body
      - JSON (The most common)
      - HTML form (Application form)
      - Form Data (Uploading images and files)
      - text
    - Headers define the format of the Body.
- Backend
    - receive the request and response data to client
    - sometimes, query data from database
    - the languages that use in backend
        - Javascipt/TypeScript
            - ex. Node.js
        - python
            - ex. Flask, django, FastAPI
        - Go
            - gin
- Database
    - the place storing data
    - receive request to create, read, update, or delete data
    - the type of database 
    - MangoDB (NoSQL)
    - Redis (NoSQL)
    - MySQL (SQL)
    - PostgreSQL (SQL)
- We will use an ORM (Object-Relational Mapper) to interact with the database
- Resful API
    - a method of communication between frontend and backend
    - API specification must include
    - which Endpoint Path?
    - which method? GET or POST ...?
    - what parameter will be? Path Parameter? Query String? Request Body?
    - which response will be? Status Code? Response Body?
